## Commands

```bash
# Install dependencies
pip install -r requirements.txt

# One-time Google OAuth token generation (run locally, requires credentials.json)
python generate_token.py

# Run development server
uvicorn main:app --reload

# Test the chat endpoint (include API key header)
curl -X POST localhost:8000/api/chat \
  -H "Content-Type: application/json" \
  -H "x-api-key: your-secret-key-here" \
  -d '{"message": "hi layla", "user_id": "test"}'

# Health check
curl localhost:8000/health
```

## Environment Variables

Copy `.env.example` to `.env` and populate:
- `GEMINI_API_KEY` — from Google AI Studio (paid tier recommended for web search)
- `GOOGLE_TOKEN_JSON` — full JSON string from `token.json` (generated by `generate_token.py`)
- `GOOGLE_CREDENTIALS_JSON` — full JSON string from Google Cloud OAuth credentials download
- `LAYLA_API_KEY` — secret key to protect the `/api/chat` endpoint (sent as `x-api-key` header)
- `MEMORY_FILE_PATH` — defaults to `memory.json` locally, `/data/memory.json` on Render
- `USER_TIMEZONE` — IANA timezone string, e.g. `Europe/London` (default)

## Architecture

The app is a FastAPI server with a single `POST /api/chat` endpoint. All intelligence runs through a Gemini function-calling agent loop. The voice interface is iOS Shortcuts (STT/TTS on-device) posting to this server.

### Request flow

1. `main.py` receives `{message, user_id}` with `x-api-key` header
2. If the message is a greeting keyword → **fast path**: query Gmail + Calendar APIs directly, return without calling the LLM
3. Otherwise → `agent.py:run_agent()` → Gemini agentic loop (up to 10 iterations)
4. Gemini returns function calls → tools execute → results fed back to Gemini → repeat until text response
5. Response: `{reply: str, action: "continue"|"stop", should_stop: true|null}`
   - `should_stop: null` → iOS Shortcut loop continues
   - `should_stop: true` → iOS Shortcut stops (triggered by `[ACTION:STOP]` in agent reply on goodbye)

### Models

- **Main agent**: `gemini-3.5-flash-lite` (in `agent.py`) — handles all conversation, tool-calling, email, calendar, memory
- **Session compaction**: `gemini-3.5-flash-lite` (in `agent.py`) — summarises old history when > 20 messages

### Module responsibilities

- **`agent.py`** — owns the Gemini model instances, all 13 `FunctionDeclaration` schemas, `TOOL_HANDLERS` dispatch dict, and the agentic loop. Adding a new tool requires: (1) a handler in `TOOL_HANDLERS`, (2) a `FunctionDeclaration` in `GEMINI_TOOLS`, (3) the actual function in `tools/`.
- **`session.py`** — in-memory session store (`_sessions` dict, lost on restart). 2-hour TTL. History compaction: when `history > 20` messages, oldest messages are summarized by Gemini and replaced with a single `[Earlier conversation summary]` block.
- **`memory.py`** — long-term memory persisted to a JSON file (`memory.json` or `/data/memory.json`). Three categories: `facts`, `preferences`, `contacts`. Contacts are auto-learned from email senders in `gmail_tools.read_emails()`.
- **`auth.py`** — Google OAuth2. Prefers env vars (`GOOGLE_TOKEN_JSON`) over local files (`token.json`). Auto-refreshes expired tokens. Re-run `generate_token.py` and update `GOOGLE_TOKEN_JSON` on Render when the token expires.
- **`tools/gmail_tools.py`** — uses Gmail batch HTTP requests (`svc.new_batch_http_request`) to fetch email metadata in parallel.
- **`tools/calendar_tools.py`** — all datetimes stored/sent as UTC ISO strings. `modify_event` preserves original duration when only `new_start` is provided. Timezone-aware via `USER_TIMEZONE` env var.
- **`tools/web_search_tools.py`** — uses the `ddgs` package (DuckDuckGo) for free real-time web search. Returns raw text results for the main Gemini model to synthesise into a spoken answer.

### Destructive tool confirmation flow

`send_email`, `reply_email`, and `delete_event` require spoken confirmation before executing. When Gemini requests one of these, the agent pauses, asks the user "Shall I go ahead?", stores a pending action in session, and waits for the next turn. "Yes" executes; "no" cancels.

### Deployment (Render)

- Deployed at: `https://layla-voice-agent-1.onrender.com`
- `render.yaml` defines the web service with a persistent disk at `/data` (for `memory.json`)
- Start command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
- Google credentials are stored as env var strings (not files) on Render
- Starter plan ($7/mo) — no sleep, always on

### Adding a new tool

1. Add the function to `tools/gmail_tools.py` or `tools/calendar_tools.py` (or a new file)
2. Register it in `TOOL_HANDLERS` in `agent.py`
3. Add its `FunctionDeclaration` to `GEMINI_TOOLS` in `agent.py`

The agentic loop handles everything else automatically.
